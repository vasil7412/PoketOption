# Rate Analyzer (Business Central 29)

Розширення завантажує й зберігає історію курсів валютних пар із легальних публічних API, будує живий свічковий графік і прогноз ціни на 3–5 хвилин уперед із коридором довіри.

## Як це працює

```
Job Queue (щохвилини) ──► SMA Rate Sync Job ──► для кожної активної пари:
                                                 1. завантажити нові свічки (провайдер)
                                                 2. побудувати й зберегти прогноз
                                                 3. порівняти дозрілі прогнози з фактом
Сторінка «Rate Analyzer» ── таймер у JS (кожні N сек) ──► те саме для однієї пари + перемалювати графік
```

* **Провайдери даних** (`enum "SMA Rate Data Provider"` + інтерфейс `"SMA IRate Data Provider"`):
  * **Binance**: без ключа, лише криптопари (BTCUSDT, ETHUSDT, EURUSDT…). Таймфрейми 1 хв і 5 хв.
  * **Twelve Data**: форекс, крипта, акції. Потрібен безкоштовний ключ (800 запитів на добу, 8 на хвилину). Таймфрейми 1 хв і 5 хв.
  * **OANDA**: форекс у реальному часі. Потрібен токен безкоштовного practice-акаунта. Таймфрейми 15 с, 30 с, 1 хв і 5 хв.
  * Новий провайдер = нове значення енуму + кодюніт, що реалізує інтерфейс.
* **Методи прогнозу** (`enum "SMA Forecast Method"` + інтерфейс `"SMA IForecast Method"`):
  * Linear Regression: лінійний тренд за останні N свічок.
  * Holt Damped Trend: експоненційне згладжування із затухаючим трендом.
  * Ensemble: середнє двох попередніх методів.
  * Коридор довіри: ± k·σ·√h, де σ — помилка прогнозу на 1 свічку, h — номер кроку.
* **Контроль якості**:
  * кожен збережений прогноз після настання цільового часу порівнюється з фактичною ціною (поле *Direction Hit Rate*);
  * **Run Backtest** проганяє всі методи по історії й показує частку вгаданих напрямів, а також *Skill %* — наскільки помилка менша за наївний прогноз «ціна не зміниться».

> ⚠️ На горизонті 3–5 хвилин курси майже не відрізняються від випадкового блукання. Влучання в напрям близько 50% і Skill ≤ 0 — це нормальний, чесний результат. Не використовуйте прогноз як торговий сигнал, доки бектест на великій вибірці не покаже стабільну перевагу.

## Встановлення

1. Відкрийте корінь репозиторію у VS Code (`app.json` лежить там, код — у `app/`). У `.vscode/launch.json` вкажіть своє середовище і виконайте **AL: Download Symbols**.
2. Діапазон ID — `50100..50149`, префікс — `SMA`. Якщо на сервері цей діапазон уже зайнятий, змініть його в `app.json`.
3. Опублікуйте розширення (F5 або Ctrl+F5) і призначте користувачам набір дозволів **SMA RATE ANALYZER**.
4. Сервер BC має мати вихід в інтернет до `api.binance.com`, `api.twelvedata.com`, `api-fxpractice.oanda.com`. Якщо в *Extension Management → Configure* є прапорець **Allow HttpClient Requests**, увімкніть його.

## Налаштування

1. **Rate Analyzer Setup**:
   * введіть ключ Twelve Data і/або токен OANDA (вони зберігаються в IsolatedStorage);
   * натисніть **Create Default Pairs** — з'являться BTCUSDT і ETHUSDT (активні, Binance), а також EURUSD, GBPUSD, USDJPY (неактивні, Twelve Data);
   * натисніть **Create Job Queue Entry** — фонове оновлення запускатиметься щохвилини.
2. **Rate Analyzer Currency Pairs**: додайте свої пари. Для кожної задайте провайдера (символ підставиться автоматично), таймфрейм, метод і горизонт прогнозу, кількість знаків ціни та прапорець *Active*.
3. Виберіть пару → **Analyzer**. На графіку:
   * свічки — фактичні котирування;
   * помаранчевий пунктир — прогноз до +H хвилин;
   * тонкий пунктир — коридор довіри;
   * сірі точки — що прогнозувалося раніше на кожну хвилину (видно, наскільки прогноз збігався з фактом).
   На сторінці можна змінити горизонт і метод «на льоту». Ці зміни впливають лише на графік, не на збережену статистику.

## Ліміти запитів

Кожна відкрита сторінка Analyzer з увімкненим *Live Fetch on Refresh* робить один запит до провайдера раз на *Refresh Interval*. Для Twelve Data на безкоштовному плані ставте інтервал ≥ 30 с і небагато активних пар: Job Queue теж витрачає один запит на пару щохвилини.
